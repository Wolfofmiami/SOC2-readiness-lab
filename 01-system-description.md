# Monvive Cloud: System Description

## Company Overview
Monvive Cloud is a booking platform that connects
homeowners with vetted handyman and home repair pros
in the Atlanta area. ~12 employees.

## Scope
IN: the booking web app, customer database,
employee accounts, and code repository.
OUT: payment card data (handled fully by Stripe;
Monvive never stores card numbers).

## 1. Infrastructure
- Web app hosted on Netlify
- Database: Supabase (customer + job data)
- Code stored in GitHub

## 2. Software
- Monvive booking app (built in-house)
- Google Workspace (email, docs)
- Stripe (payments)
- Slack (internal chat)

## 3. People
- CEO / Owner
- CTO (manages all tech + security)
- 3 developers
- 1 operations manager
- 1 customer support rep
- 5 field technicians (use mobile app only)

## 4. Data
- Customer names, emails, phone numbers
- Home addresses
- Job photos and notes
- Classification: Confidential

## 5. Procedures
- New hires get accounts on day one
- Code changes are pushed to GitHub, then Netlify
- Customer issues handled via support email
